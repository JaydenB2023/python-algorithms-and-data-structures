# Python Algorithms & Data Structures

A collection of Python implementations exploring fundamental algorithms and data structures, developed while pursuing my Master of Science in Software Engineering.

## Projects

| Project | Concepts | Time Complexity |
|---|---|---|
| Bubble Sort | Sorting, benchmarking, performance analysis | O(n²) |
| Maximum Subarray | Brute force, divide-and-conquer, recursion | O(n²) / O(n log n) |
| Longest Common Subsequence | Dynamic programming, sequence reconstruction | O(mn) |
| Heap Merging | Min-heaps, max-heaps, bottom-up heap construction | Θ(N) |

## Technologies

- Python
- Matplotlib
- Algorithm analysis and benchmarking

## About

These projects explore different algorithmic approaches, their computational efficiency, and practical implementation in Python. Each project focuses on understanding how algorithms work and evaluating their time complexity.
